# Film covers — review batch 01

Ten sample covers generated individually using the app's `buildFilmCoverPrompt` text-only prompt.
Each product has its exact prompt saved alongside its image. Originals remain here; normalized copies have now replaced the app's runtime PNGs at the existing `FILM_ASSETS` paths. Generation uses the built-in imagegen tool,
without an API key or an application API integration.

Target: one flat front printed face, edge-to-edge, landscape 123:100 (1230 × 1000 preferred).
Actual dimensions are recorded in the manifest after generation; tool output is not silently
stretched or cropped. Packaging fidelity is approximate and needs human review, especially fine
print, edition-specific graphics and wordmarks. Preserve catalog product names; do not substitute
new Kodak Ektacolor branding for a requested Portra stock.

Manufacturer sources consulted on 2026-10-29:
- https://kodakprofessional.com/sites/default/files/files/resources/Kodak%20Catalogue%20-%20Final%20-%20High%20Res%20%28Print%29.pdf
- https://www.kodakprofessional.com/sites/default/files/wysiwyg/film/KODAKPROFESSIONAL_Film_Brochure2018.pdf
- https://www.ilfordphoto.com/retro-packaging/
- https://www.fujifilm.com/nz/en/consumer/support/films/negative-and-reversal

The source lookup does not certify every generated pixel. Check spelling, ISO, full artwork,
packaging edition, layout, background and actual output ratio before approving replacements.
