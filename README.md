# FILMER

**A Digital Archive for Film Photography**

FILMER is a mobile app that helps film photography enthusiasts organize their film rolls, cameras, and scanned photos in one place.

## Product Vision

FILMER aims to make film photography archiving simple and convenient.

Users can organize photos by film roll, record camera and film information, and easily revisit their photography memories.

## Features

**Core MVP Features**
- Create, edit, and delete film rolls
- Select cameras and film stocks
- Record film information (ISO, format, date)
- Import scanned photos from the device gallery
- Organize and view photos by film roll
- View individual photos in a gallery

**Planned Features**
- Google Sign-In
- Local storage and cloud synchronization
- Search and filter film rolls
- Photography statistics

## MVP Status

The MVP is currently in the initial development stage.

**Currently available:**
- React Native + Expo project setup
- TypeScript configuration
- Basic project structure
- Initial UI/UX design
- iOS Simulator environment

### Core Workflow

**Create Roll → Select Film & Camera → Add Photos → View Roll → View Photos**

### Current Limitations

The following features are still under development:
- Film roll management
- Photo import and gallery
- Google authentication
- Local data storage
- Cloud synchronization
