# Zoom gesture and periodic Home image refresh fixes

Date: 2026-10-27 (Asia/Seoul).

## Confirmed source causes and changes

- The cloud driver performs a reference repair after each successful metadata sync (including foreground and periodic polls). Repair previously invalidated all photo renders at both start and finish. This notified every mounted photo hook, changed its render identity and temporarily hid the previous URI. Automatic metadata checks now opt out of those global invalidations. Each reference is still directly verified, unresolved counts still update, and repaired identifiers publish through the roll store. Explicit user repair retains its normal refresh behavior. Real library/foreground events, manual Retry and cache cleanup retain their existing invalidation paths; cached images still cannot override a failed access check.
- Viewer pan and pinch shared translation anchors and could start independent decay/settle animations as fingers were lifted. Pinch now has separate anchors, cancels in-progress transform/page/dismiss animations before taking ownership, and may take over even when the simultaneous pan initially classified as a page gesture. Pan ignores multi-touch updates and pinch completion; one-finger continuation rebases from the live transform and stops the pinch settle first. Pinch finalization also releases ownership on native cancellation.

No native module/API, dependency, archive schema, photo file, original image or cloud record changes. Existing uncommitted project work was preserved. This patch does not disable cloud sync or retain unauthorized previews after actual Photos invalidation.
